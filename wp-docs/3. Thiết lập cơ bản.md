## 🎨 2. CÔNG NGHỆ CSS ĐANG SỬ DỤNG

Theme `leadershub-wp-theme` áp dụng **kiến trúc CSS hiện đại, linh hoạt & tối ưu tốc độ tải trang**:

### ⚡ A. Tailwind CSS (Framework chính)
- **Phương thức tích hợp:** Sử dụng **Tailwind CSS Play CDN v3** (load trực tiếp qua Script CDN trong `header.php` để kết xuất Utility Classes nhanh chóng mà không cần qua bước biên dịch npm heavy build).
- **Hệ màu nhận diện thương hiệu (Custom Color System):**
  - `deep-navy` (`#0A192F` / `#0B192C`): Màu xanh đen chủ đạo cao cấp.
  - `prestige-gold` (`#D4AF37`): Màu vàng kim điểm nhấn sang trọng.
  - `surface-container`, `surface-container-high`, `on-surface-variant`: Màu nền thẻ và văn bản chuẩn Material Design.
- **Scale Font chữ chuẩn (Typography Scale):**
  - Khai báo hệ thống typography map trong `functions.php` (`fontSize`: `display-lg`, `headline-md`, `body-md`, `label-sm`...).

### 🎯 B. CSS Tùy chỉnh (Vanilla CSS trong `style.css`)
- **Nạp chính thức:** Được enqueued chính thức qua `wp_enqueue_style('leadershub-style')` trong `functions.php`.
- **Nhiệm vụ chính:**
  1. **Bè phông chữ Inter cho Google Reviews Widget:** Ghi đè Font-family của Trustindex widget (`.google-reviews-widget-container`, `.ti-widget`, `.ti-name`, `.ti-review-content`) bắt buộc dùng font `'Inter'`.
  2. **Định dạng danh sách bài viết & WYSIWYG (`ul`, `li`):** 
     - Gỡ bỏ dấu chấm đầu dòng mặc định của trình duyệt (`list-style: none`).
     - Tự động thay thế bằng **Icon tích xanh vàng kim (`check_circle`)** chuẩn `Material Symbols Outlined` cho các mục danh sách.
     - Căn chỉnh flexbox, khoảng cách `gap` và giãn dòng `line-height: 1.6` tối ưu đọc tin.

### 🎠 C. Thư viện hiệu ứng CSS bên ngoài
- **Swiper CSS v11.1.14 (`swiper-bundle.min.css`):** Được nạp ở `<head>` để phục vụ các khối Slide chuyển động (Slider Dịch vụ, Slider Chứng nhận & Tiêu chuẩn dạng Card, Slider Hình ảnh thực tế tòa nhà).
- **Google Material Symbols Outlined & Google Fonts:** Tích hợp bộ icon Material Symbols và các font chữ Google Fonts (`Inter`, `Playfair Display`, `Plus Jakarta Sans`).
