# Hướng Dẫn Thiết Lập Git Version Control trên Hosting Vietnix (cPanel)

Tài liệu hướng dẫn kết nối kho lưu trữ GitHub dự án **Leaders Hub** với Hosting **Vietnix (cPanel)** và cấu hình **Tự động Deploy (Auto-Deploy)** khi cập nhật code.

---

## 📌 1. Thông tin chung
- **Repository URL:** `https://github.com/vanvupv/leadershub.git`
- **SSH URL:** `git@github.com:vanvupv/leadershub.git`
- **Hosting Provider:** Vietnix (cPanel)
- **Cấu trúc Deploy:**
  - **Option A (Khuyên dùng - Full Website):** Deploy vào `public_html`
  - **Option B (Chỉ Theme):** Deploy vào `public_html/wp-content/themes/leadershub-wp-theme`

## 🔑 2. Bước 1: Tạo và cấu hình SSH Key trên Vietnix cPanel

1. Truy cập vào trang quản trị **cPanel** của Vietnix.
2. Tìm đến mục **Security** -> chọn **SSH Access**.
3. Nhấp vào **Manage SSH Keys** -> chọn **Generate a New Key**.
4. Điền các thông số:
   - **Key Name:** `id_rsa` (hoặc `leadershub_deploy`)
   - **Key Password:** *Để trống* (không nhập mật khẩu để hệ thống Auto-Deploy tự động chạy không bị hỏi Passphrase).
   - **Key Type:** `RSA`
   - **Key Size:** `4096`
5. Nhấn **Generate Key**.
6. Quay lại màn hình **Manage SSH Keys**:
   - Tại mục **Public Keys**, tìm key vừa tạo và nhấn **Manage Authorization** -> Chọn **Authorize**.
   - Nhấn **View/Download** ở dòng Public Key -> **Copy toàn bộ chuỗi Public Key**.

---

## 🐙 3. Bước 2: Thêm SSH Key vào GitHub (Deploy Keys)

1. Truy cập vào Repository trên GitHub: [https://github.com/vanvupv/leadershub.git](https://github.com/vanvupv/leadershub.git)
2. Vào **Settings** (của Repo) -> chọn **Deploy keys** (ở danh mục menu bên trái).
3. Nhấn **Add deploy key**:
   - **Title:** `Vietnix cPanel Deploy Key`
   - **Key:** Dán chuỗi Public Key đã copy ở Bước 1 vào đây.
   - **Allow write access:** Tick chọn (nếu muốn cho phép push ngược từ server lên GitHub, nếu chỉ pull code về server thì không cần).
4. Nhấn **Add key**.

## 🌐 4. Bước 3: Tạo Repository trong cPanel Git™ Version Control

> ⚠️ **LƯU Ý QUAN TRỌNG VỀ REPO TRỐNG & THƯ MỤC CÓ SẴN:**
> - **Nếu bạn chọn Clone vào thư mục đã có sẵn dữ liệu** (`/home/bydhado1/leadershub.demoweb360.top`), cPanel sẽ **báo lỗi ngay lập tức (`Directory is not empty`)** và không cho clone.
> - **Nếu Repo trên GitHub chưa có commit nào (Repo trống)**, cPanel cũng không thể clone được vì chưa có nhánh (branch) để checkout.
>
> 👉 **Giải pháp đúng quy trình:** Bạn cần đẩy (push) code từ máy local hoặc từ server lên GitHub lần đầu tiên trước (xem phần hướng dẫn chi tiết bên dưới).

### Quy trình tạo Repo trên cPanel:
1. Trong cPanel, tìm đến mục **Files** -> chọn **Git™ Version Control**.
2. Nhấn nút **Create**:
   - Bật công tắc **Clone a Repository**.
   - **Clone URL:** `git@github.com:vanvupv/leadershub.git` *(Dùng SSH URL)*
   - **Repository Path:** `/home/bydhado1/repositories/leadershub` *(Khuyên dùng lưu vào thư mục riêng, sau đó `.cpanel.yml` sẽ copy sang `leadershub.demoweb360.top`)*
   - **Repository Name:** `leadershub`
   - **Branch:** `main`
3. Nhấn **Create**.

## ⚙️ 5. Bước 4: Tạo file Cấu hình Deploy `.cpanel.yml`

Để cPanel biết cần copy những file nào sau khi `git pull`, bạn cần tạo file `.cpanel.yml` nằm ở **thư mục gốc (root)** của repository trên máy tính và commit lên GitHub.

Nội dung file `.cpanel.yml`:

```yaml
---
deployment:
  tasks:
    - export DEPLOYPATH=/home/username/public_html/
    - /bin/cp -R * $DEPLOYPATH
```

> **Lưu ý:**
> - Thay `username` bằng tên tài khoản cPanel Vietnix của bạn.
> - Nếu dự án repository này chỉ chứa riêng theme `leadershub-wp-theme`, điều chỉnh `DEPLOYPATH` thành:  
>   `export DEPLOYPATH=/home/username/public_html/wp-content/themes/leadershub-wp-theme/`

Sau khi tạo file `.cpanel.yml`, hãy push file này lên GitHub:
```bash
git add .cpanel.yml
git commit -m "Add .cpanel.yml auto-deploy configuration"
git push origin main
```

## 🔄 6. Bước 5: Cấu hình Webhook Tự Động Deploy (Auto-Deploy)

Mỗi khi bạn `git push` code mới lên GitHub, Webhook sẽ tự gửi tín hiệu kích hoạt cPanel kéo code mới nhất về và chạy `.cpanel.yml`.

1. **Lấy URL Webhook trên cPanel:**
   - Vào cPanel -> **Git™ Version Control** -> Tìm repo `leadershub` -> Nhấn **Manage**.
   - Chọn tab **Basic Information**, tìm mục **Webhook URL** (URL sẽ có dạng: `https://your-domain.com:2083/cpsessXXXXX/frontend/paper_lantern/git/deploy.live.php...` hoặc API Trigger URL).

2. **Thêm Webhook vào GitHub:**
   - Vào GitHub Repo -> **Settings** -> **Webhooks** -> Nhấn **Add webhook**.
   - **Payload URL:** Dán URL Webhook vừa chép ở cPanel.
   - **Content type:** `application/json`
   - **Which events would you like to trigger this webhook?:** Chọn `Just the push event`.
   - Nhấn **Add webhook**.

## 🚀 7. Quy trình Thao tác & Kiểm tra (Deploy Workflow)

### Kéo code thủ công (Manual Pull / Deploy):
Nếu không dùng Webhook, bạn có thể thực hiện thao tác kéo code thủ công trong cPanel:
1. Vào cPanel -> **Git™ Version Control** -> **Manage** (Repo `leadershub`).
2. Chọn tab **Pull or Deploy**.
3. Nhấn **Update from Remote** (để `git pull` bản mới nhất về).
4. Nhấn **Deploy HEAD Revision** (để chạy các tác vụ copy file trong `.cpanel.yml`).

## 💡 8. Các sự cố thường gặp (Troubleshooting)

| Sự cố | Nguyên nhân | Cách khắc phục |
| :--- | :--- | :--- |
| **Error: Host key verification failed** | cPanel chưa nhận diện được RSA Key của GitHub | Kết nối SSH vào cPanel và chạy lệnh: `ssh -T git@github.com` để xác nhận fingerprint (`yes`). |
| **Deploy HEAD Revision bị xám (disabled)** | Thiếu file `.cpanel.yml` hoặc file bị sai cú pháp YAML | Kiểm tra file `.cpanel.yml` có ở nhánh `main` trên GitHub chưa. Sử dụng công cụ YAML Validator để check cú pháp. |
| **Permission Denied (publickey)** | Public Key chưa được Authorize hoặc Deploy key trên GitHub chưa khớp | Vào **SSH Access** -> **Manage Authorization** -> Chọn **Authorize** cho key `id_rsa`. Kiểm tra xem đã dán đúng Public Key lên GitHub Deploy Key chưa. |
